# SimpleUIScreensSystem
*Примечание: документация частично создана с использованием ИИ-помощника*</br></br>
Простая и эффективная система управления экранами интерфейса для Unity, позволяющая легко переключаться между различными UI-экранами с поддержкой анимаций и асинхронных операций.

## Описание

`SimpleUIScreensSystem` — это легковесный фреймворк для управления UI-экранами в Unity проектах. Система предоставляет:

- **Управление экранами** — регистрация, открытие и закрытие UI-экранов
- **Анимации переходов** — встроенная поддержка fade и scale анимаций
- **Гибкие функции интерполяции** — встроенные easing функции (linear, spring, ease-in, ease-out и т.д.)

## Основные компоненты

### Адаптивная загрузка через Addressables

`AddressableUIRoot` загружает сверстанные вручную uGUI-prefab'ы по запросу и
предзагружает вероятные следующие экраны. `AddressableScreenCatalog` задаёт
приоритеты, ссылки и бюджеты; `ScreenPopularityPolicy` обучается на успешных
открытиях и действиях пользователя, постепенно уменьшая вес старых наблюдений.

Вызовы используют типизированные ключи: `_navigator.Open(Screens.Settings)`.
Класс `Screens` генерируется из каталога в проект пользователя; стабильные ID
сохраняются при переименовании экранов и замене prefab. Для кнопок предусмотрен
`AddressableScreenActions` с выбором экрана в инспекторе.

Поддерживаются объединение повторных запросов, резерв слота для пользовательской
загрузки, ограниченный кеш и безопасное освобождение handles после уничтожения
экземпляров. Сценовый `UINavigator` и `AddressableUIRoot` используют один тип ключа `ScreenId`.

Требования текущей версии: **Unity 6.0+, uGUI 2.0, Addressables 2.7.6**.

[Настройка, алгоритм, ограничения и пример кода](Documentation~/addressable-screen-cache.md).

### UIScreen
Базовый класс для всех UI-экранов. Предоставляет методы для инициализации, открытия, закрытия и управления состоянием экрана.

**Основные методы:**
- `Init()` — инициализация экрана
- `Open()` — открытие экрана
- `Close()` — закрытие экрана
- `OnEnable()`, `OnDisable()` — управление активностью

### UINavigator
Реестр экранов, размещённых в сцене. `UIInitializer` регистрирует их на старте по значению поля **ID** компонента `UIScreen`.

**Основные методы:**
- `Add(UIScreen screen)` / `Remove(UIScreen screen)` — регистрация и снятие с учёта
- `Open(ScreenId screenId, Action closeCallback = null)` — открытие экрана; callback срабатывает один раз при закрытии
- `Close(ScreenId screenId)` — закрытие экрана
- `CloseAll()` — закрытие всех открытых экранов
- `TryGetScreen(ScreenId screenId, out UIScreen screen)` — получение экрана

### ScreenId
Типизированный ключ экрана вместо enum. Для экранов из каталога Addressables класс ключей генерируется командой **Generate Screen Keys...**; для сценовых экранов ключи объявляются в проекте вручную и совпадают с полем **ID** на `UIScreen`:

```csharp
public static class Screens
{
    public static readonly ScreenId Demo = new ScreenId("demo");
}

UINavigator.Instance.Open(Screens.Demo);
```

Добавление экранов не требует изменения пакета.

## Установка

1. Откройте **Package Manager**
2. Нажмите **"+"** и выберите **"Add package from git URL..."**
3. Вставьте ссылку:
   ```
   https://github.com/alpershin/SimpleUIScreensSystem.git
   ```
4. Нажмите **Add**
